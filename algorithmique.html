Développement – Algorithmique

Trois algorithmes : idée générale, pseudo-code, exemple pas à pas et traduction en Python.

Algorithme 1 – Recherche du maximum

Idée générale : on suppose que le premier élément est le maximum, puis on parcourt le tableau et on retient tout élément plus grand.

FONCTION maximum(T, n)
    max ← T[0]
    POUR i DE 1 À n-1 FAIRE
        SI T[i] > max ALORS
            max ← T[i]
        FIN SI
    FIN POUR
    RETOURNER max

Exemple pas à pas avec T = [4, 9, 2, 7] : max = 4 → 9 > 4 donc max = 9 → 2 < 9 → 7 < 9 → résultat 9.

def maximum(t):
    m = t[0]
    for x in t[1:]:
        if x > m:
            m = x
    return m

print(maximum([4, 9, 2, 7]))  # 9

Algorithme 2 – Tri à bulles

Idée générale : on compare les éléments voisins et on les échange s'ils sont mal ordonnés. À chaque passage, le plus grand élément « remonte » en fin de tableau.

PROCÉDURE triBulles(T, n)
    POUR i DE 0 À n-2 FAIRE
        POUR j DE 0 À n-i-2 FAIRE
            SI T[j] > T[j+1] ALORS
                échanger T[j] et T[j+1]
            FIN SI
        FIN POUR
    FIN POUR

Exemple pas à pas avec [5, 2, 4] :

  • Passage 1 : (5,2) échange → [2, 5, 4] ; (5,4) échange → [2, 4, 5]
  • Passage 2 : (2,4) correct ; le tableau est trié : [2, 4, 5]
def tri_bulles(t):
    n = len(t)
    for i in range(n - 1):
        for j in range(n - i - 1):
            if t[j] > t[j + 1]:
                t[j], t[j + 1] = t[j + 1], t[j]
    return t

print(tri_bulles([5, 2, 4]))  # [2, 4, 5]

Complexité : de l'ordre de n² comparaisons dans le pire cas.

Algorithme 3 – Recherche dichotomique

Idée générale : dans un tableau trié, on compare la valeur cherchée à l'élément du milieu et on élimine la moitié du tableau à chaque étape.

FONCTION dichotomie(T, n, x)
    gauche ← 0 ; droite ← n-1
    TANT QUE gauche ≤ droite FAIRE
        milieu ← (gauche + droite) DIV 2
        SI T[milieu] = x ALORS RETOURNER milieu
        SINON SI T[milieu] < x ALORS gauche ← milieu + 1
        SINON droite ← milieu - 1
    FIN TANT QUE
    RETOURNER -1

Exemple pas à pas : T = [1, 3, 5, 7, 9, 11], x = 7 → milieu = 2 (valeur 5 < 7) donc gauche = 3 → milieu = 4 (valeur 9 > 7) donc droite = 3 → milieu = 3 (valeur 7) : trouvé à l'indice 3.

def dichotomie(t, x):
    gauche, droite = 0, len(t) - 1
    while gauche <= droite:
        milieu = (gauche + droite) // 2
        if t[milieu] == x:
            return milieu
        if t[milieu] < x:
            gauche = milieu + 1
        else:
            droite = milieu - 1
    return -1

print(dichotomie([1, 3, 5, 7, 9, 11], 7))  # 3
