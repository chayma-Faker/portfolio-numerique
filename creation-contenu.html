Digital Skills – Création de contenu

Sujet choisi : [ex. « La sécurité sur Internet »]. Toutes les productions ci-dessous traitent ce même sujet.

Utilisez uniquement des images, musiques et voix dont vous avez le droit (libres de droits ou générées). Aucun logiciel ou clé piraté.

1. Avatar parlant

Description : vidéo de 30 à 60 secondes où un avatar présente le sujet à partir d'un script écrit et relu par moi.

Outils : HeyGen (ou équivalent).

À compléter : ajoutez votre vidéo.

2. Montage vidéo

Description : vidéo avec sous-titres, musique libre de droits et transitions sobres.

Outils : CapCut.

À compléter : intégrez ou liez votre vidéo (../medias/montage.mp4) et citez la source de la musique.

3. Résumé

Description : résumé structuré du sujet, généré puis corrigé par moi.

Outils : NotebookLM.

À compléter : collez votre résumé corrigé ici et indiquez ce que vous avez modifié.

4. Podcast

Description : épisode audio de quelques minutes généré à partir de mes sources.

Outils : NotebookLM.

À compléter :

5. Carte mentale

Description : concepts clés du sujet et liens entre eux.

Outils : NotebookLM, Canva.

6. PowerPoint interactif avec voix

Description : présentation avec boutons de navigation, menu cliquable (liens internes) et narration vocale sur chaque diapositive à partir d'un script (2 à 4 phrases par diapositive).

Outils : PowerPoint (enregistrement de narration), Canva, Gamma.

À compléter : liez l'export (../medias/presentation.pdf ou vidéo) et décrivez votre menu de navigation.
