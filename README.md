## Objectif du projet

Ce dépôt contient mon portfolio numérique : un site web hébergé sur GitHub Pages qui présente mes réalisations dans chaque module du semestre, et la manière dont j'utilise les outils d'IA de façon responsable, critique et efficace.

| Systèmes d'exploitation et fondements | Systèmes d'exploitation, architecture et électronique |
| Développement web côté client | Réalisation de ce site (HTML, CSS, JavaScript) |

Chaque page de production se termine par une fiche « Transparence IA » (outils, rôle de l'IA, ce que j'ai fait moi-même, sources vérifiées).

## Mise en ligne (GitHub Pages)

1. Créer un dépôt public nommé `portfolio-numerique`.
2. Y déposer tous les fichiers de ce dossier.
3. Aller dans *Settings → Pages → Branch : main → Save*.
4. Attendre quelques minutes, puis ouvrir l'adresse du site.
