Projet 1 – Calculatrice

Problème : demander deux nombres et une opération (+, -, *, /) puis afficher le résultat, en gérant la division par zéro et les saisies invalides.

def calculer(a, b, op):
    if op == "+":
        return a + b
    if op == "-":
        return a - b
    if op == "*":
        return a * b
    if op == "/":
        if b == 0:
            return None
        return a / b
    return None

try:
    a = float(input("Premier nombre : "))
    b = float(input("Deuxième nombre : "))
    op = input("Opération (+, -, *, /) : ")
    resultat = calculer(a, b, op)
    if resultat is None:
        print("Opération impossible (division par zéro ou symbole inconnu).")
    else:
        print("Résultat :", resultat)
except ValueError:
    print("Veuillez entrer un nombre valide.")

Explication : la fonction calculer choisit l'opération avec des conditions. Le bloc try / except intercepte l'erreur levée par float() si l'utilisateur tape du texte.

Projet 2 – Jeu de devinettes

Problème : l'ordinateur choisit un nombre entre 1 et 100 ; le joueur propose des valeurs et reçoit « trop grand » ou « trop petit » jusqu'à trouver.

import random

secret = random.randint(1, 100)
essais = 0

print("J'ai choisi un nombre entre 1 et 100.")
while True:
    saisie = input("Votre proposition : ")
    if not saisie.isdigit():
        print("Entrez un nombre entier.")
        continue
    proposition = int(saisie)
    essais += 1
    if proposition < secret:
        print("Trop petit.")
    elif proposition > secret:
        print("Trop grand.")
    else:
        print("Bravo ! Trouvé en", essais, "essais.")
        break

Explication : random.randint tire le nombre secret. La boucle while True continue jusqu'au break. Le compteur essais mesure la performance.

Projet 3 – Gestionnaire de notes

Problème : saisir des notes, puis afficher la moyenne, la meilleure et la plus faible.

notes = []

while True:
    saisie = input("Note sur 20 (ou 'q' pour terminer) : ")
    if saisie.lower() == "q":
        break
    try:
        note = float(saisie)
    except ValueError:
        print("Valeur invalide.")
        continue
    if 0 <= note <= 20:
        notes.append(note)
    else:
        print("La note doit être entre 0 et 20.")

if notes:
    moyenne = sum(notes) / len(notes)
    print("Nombre de notes :", len(notes))
    print("Moyenne :", round(moyenne, 2))
    print("Meilleure :", max(notes))
    print("Plus faible :", min(notes))
else:
    print("Aucune note saisie.")

Explication : les notes sont stockées dans une liste. On valide chaque entrée avant de l'ajouter, puis on utilise sum, max et min.
