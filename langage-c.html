Développement – Langage C

Trois programmes illustrant les notions vues, compilés avec GCC : gcc programme.c -o programme -Wall.

Exemples de départ : adaptez-les aux notions vues en cours et écrivez d'abord votre propre version.

Programme 1 – Table de multiplication (variables, boucle)

#include <stdio.h>

int main(void) {
    int n;
    printf("Table de quel nombre ? ");
    if (scanf("%d", &n) != 1) {
        printf("Entrée invalide.\n");
        return 1;
    }
    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
    return 0;
}

Explication : scanf lit un entier ; on vérifie son code retour. La boucle for affiche les 10 premiers multiples.

Programme 2 – Maximum d'un tableau (tableaux, fonctions, conditions)

#include <stdio.h>

int maximum(int tab[], int taille) {
    int max = tab[0];
    for (int i = 1; i < taille; i++) {
        if (tab[i] > max) {
            max = tab[i];
        }
    }
    return max;
}

int main(void) {
    int valeurs[] = {12, 7, 25, 3, 18};
    int taille = sizeof(valeurs) / sizeof(valeurs[0]);
    printf("Maximum : %d\n", maximum(valeurs, taille));
    return 0;
}

Explication : en C, un tableau passé à une fonction ne conserve pas sa taille : on la transmet à part. sizeof permet de la calculer dans main.

Programme 3 – Échange de deux valeurs (pointeurs)

#include <stdio.h>

void echanger(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 5, y = 9;
    printf("Avant : x=%d, y=%d\n", x, y);
    echanger(&x, &y);
    printf("Après : x=%d, y=%d\n", x, y);
    return 0;
}

Explication : on passe les adresses de x et y (&x). La fonction modifie les valeurs pointées avec *a et *b, ce qu'un passage par valeur ne permettrait pas.
