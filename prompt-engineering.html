Digital Skills – Prompt engineering

Objectif : apprendre à formuler des demandes précises pour obtenir de meilleurs résultats d'une IA.

1. Les éléments d'un bon prompt

ÉlémentQuestion à se poserExemple
RôleQui doit répondre ?« Tu es un professeur d'informatique pour débutants. »
ContexteQuelle est la situation ?« Je suis étudiant en 1ère année et je prépare un exposé. »
TâcheQue faut-il faire exactement ?« Explique la différence entre RAM et disque dur. »
Format de sortieSous quelle forme ?« Réponds avec un tableau de 3 lignes. »
ContraintesQuelles limites ?« Maximum 120 mots, sans jargon. »
ExemplesÀ quoi ressemble une bonne réponse ?« Voici un exemple du style attendu : … »

2. Techniques utiles

  • Raisonnement étape par étape : demander de détailler les étapes avant la réponse finale.
  • Fournir des exemples (few-shot) pour fixer le style et le format.
  • Itérer et affiner : corriger le prompt en fonction du résultat obtenu.
  • Demander une vérification : « Relis ta réponse et signale les points incertains. »

3. Cas pratiques

Les cas ci-dessous sont des modèles de structure. Remplacez les résultats par vos propres tests (résumé ou capture d'écran) et gardez vos prompts réels.

Cas 1 – Expliquer un concept

Prompt initial (faible)

Explique les réseaux.

Résultat obtenu : [votre résumé ou capture – ex. réponse trop longue et trop générale]

Prompt amélioré

Tu es un professeur d'informatique pour débutants.
Je suis étudiant en 1ère année.
Explique la différence entre un switch et un routeur.
Format : un tableau de 3 critères puis une analogie en 2 phrases.
Contraintes : 150 mots maximum, sans jargon inutile.

Résultat obtenu : [votre résumé ou capture – ex. réponse courte, structurée, adaptée]

Analyse : [ce qui a changé : rôle, contexte, format et contrainte de longueur ; pourquoi la réponse est plus utile]

Cas 2 – Comprendre une erreur de code

Prompt initial (faible)

Mon code Python ne marche pas, corrige.

Résultat obtenu : [votre résumé ou capture]

Prompt amélioré

Je débute en Python. Voici mon code et le message d'erreur exact :
[code] / [erreur]
Ne me donne pas la solution complète.
1) Explique la cause de l'erreur en termes simples.
2) Donne un indice pour que je corrige moi-même.
3) Vérifie ensuite ma correction si je te la montre.

Résultat obtenu : [votre résumé ou capture]

Analyse : [ex. contexte fourni, demande d'indice plutôt que de réponse toute faite, respect de la règle « écrire d'abord ma propre solution »]

Cas 3 – Préparer une révision

Prompt initial (faible)

Fais-moi un résumé du cours.

Résultat obtenu : [votre résumé ou capture]

Prompt amélioré

Tu es un tuteur qui m'aide à réviser mon examen d'algorithmique.
À partir du texte ci-dessous, fais :
1) un résumé en 5 points clés,
2) 5 questions de révision avec réponses,
3) les 2 notions les plus faciles à confondre.
Texte : [coller le cours]
Si une information n'est pas dans le texte, dis-le.

Résultat obtenu : [votre résumé ou capture]

Analyse : [ex. structure demandée, limitation au texte fourni pour éviter les inventions]

5. Bibliothèque de prompts réutilisables

1. Expliquer simplement

Explique-moi [notion] comme si j'avais 15 ans. Donne une analogie du quotidien et un exemple concret. 120 mots maximum.

2. Fiche de révision

À partir de ce cours : [texte], crée une fiche de révision : définitions, formules ou règles clés, 3 pièges classiques. Format : liste courte.

3. Quiz d'entraînement

Pose-moi 5 questions de difficulté croissante sur [sujet], une par une. Attends ma réponse avant de corriger et explique mes erreurs.

4. Comprendre une erreur de code

Voici mon code [code] et l'erreur [erreur]. Explique la cause et donne-moi un indice, sans la solution complète.

5. Vérifier une information

Relis ta réponse précédente. Liste ce qui est certain, ce qui est incertain et ce que je dois vérifier dans une source officielle.
